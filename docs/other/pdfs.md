# PDF

PDFs are managed by the [Docs module](../modules/docs/index.md), where they can be browsed, filtered by author and
subject, searched, and read directly in the browser with the embedded PDF viewer.

WROLPi does not remember your page in a PDF: the browser's PDF viewer does not report it. See
[Resume Where You Left Off](../system/viewing-progress.md).

## Searching

When indexes for a PDF are generated, they are searched in the following order of precedence:

1. Title
2. Author
3. File path name
4. Text
